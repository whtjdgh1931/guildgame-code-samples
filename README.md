# 출격! 용병단 · GuildGame

조성호의 Unity 2D 1인 개발 프로젝트입니다. 플레이어가 주인공을 직접 조작하고, 배치한 아군은 자동으로 적을 탐색해 전투합니다. PC와 모바일을 대상으로 개발했습니다.

| 구분 | 내용 |
| --- | --- |
| 엔진·언어 | Unity 2022.3 LTS · C# |
| 전투 | 병사 FSM, 기본 공격과 스킬 쿨타임, 전투 중 HP UI 갱신 |
| 성장·진행 | CSV 기반 캐릭터 스탯, 스테이지 해금과 클리어 저장 |
| UI | 드래그·터치로 병사 배치, 스테이지 버튼 재사용 |

## 코드 샘플

- [병사 전투 FSM](01-soldier-combat.md)
- [스테이지 해금과 버튼 재사용](02-stage-panel.md)

코드는 원본 프로젝트의 일부를 발췌했습니다. 실행에는 Unity 씬과 프리팹, 프로젝트 설정이 필요합니다.
