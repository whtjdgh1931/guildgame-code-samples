# 출격! 용병단 · GuildGame

**조성호 · 1인 개발 · Unity 2022.3 LTS / C# · PC·모바일**

주인공을 직접 조작하면서 배치한 아군 병사로 전투를 진행하는 2D 전략 액션 게임입니다.

[Unity 데모](UnityDemo) · [병사 전투 FSM](01-soldier-combat.md) · [스테이지 해금과 버튼 재사용](02-stage-panel.md)

## 핵심 구현

| 기능 | 구현 방식 |
| --- | --- |
| 병사 전투 FSM | 탐색 → 이동 → 공격을 분리했습니다. 대상이 사라지면 탐색으로 돌아가고, 스턴 중에는 상태 갱신을 멈춥니다. 기본 공격과 스킬은 각각의 쿨타임으로 관리합니다. |
| 배치와 전투 UI | 드래그·터치로 병사를 배치합니다. 전투 중에는 병사의 월드 좌표를 화면 좌표로 변환해 체력 표시 위치를 갱신합니다. |
| 스테이지 진행 | 이전 스테이지의 클리어 여부로 다음 스테이지를 해금합니다. 패널을 다시 열 때 클리어·해금·잠금 상태에 맞는 버튼을 풀에서 가져옵니다. |
| 캐릭터 스탯 | CSV에서 캐릭터 스탯을 읽어 전투 로직에서 사용합니다. |

스테이지 패널을 닫을 때는 반환할 버튼을 먼저 모읍니다. 풀에 반환하는 동안 패널의 자식 목록이 바뀌어도 반환 대상을 빠뜨리지 않기 위한 구조입니다. [StagePanel.cs 발췌](02-stage-panel.md)

## Unity 데모 실행

1. 저장소를 내려받은 뒤 Unity Hub에서 `UnityDemo` 폴더를 추가합니다.
2. Unity **6000.4.8f1**에서 `Assets/Scenes/PortfolioDemo.unity`를 열고 **Play**를 누릅니다.
3. **Guard**와 **Archer**를 배치하고 **Start battle**을 누릅니다. 전투 상태와 체력 변화를 보고 스테이지를 클리어한 뒤 **Next stage**로 이동합니다.

데모 화면은 Unity 기본 GUI로 구성했습니다. 외부 에셋 구매나 서비스 계정 없이 실행할 수 있습니다.

코드 문서는 원본 전투·스테이지 로직의 C# 발췌입니다. 데모는 병사 상태 전환과 해금 흐름을 확인할 수 있도록 별도로 구성했습니다.
